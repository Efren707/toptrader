## Current focus

**US-14 (Redesign the stock details page) is implemented on `feature/us-14-stock-details-redesign`, the fifth and final story in Milestone #12 (UI/UX Polish Pass) — issue [#39](https://github.com/Efren707/toptrader/issues/39), not yet merged.** `stock-details.html` is now a 2-column grid (`minmax(0, 65fr) minmax(0, 35fr)`, collapsing to one column under 60rem, matching the pattern in `login.css`): left column has company name/price/day change plus a position-stats block (equity, today's/total return $ and %, average cost basis, shares owned, and a portfolio-diversity % — `position.marketValue` against `cashBalance + Σ all holdings' marketValue`) when a holding exists. `TradeForm` was reworked from two side-by-side Buy/Sell instances into one: `side` is now an internal signal switched by a text-tab toggle (underlined + full-color when active, hidden entirely for Sell when `hasHolding()` is false) instead of an `input()`. The quantity field is a native digit-filtered input (`toSignal` off the form control's `valueChanges` drives a live `pendingCost` computed) with its error only shown after a submit attempt, not on blur. Submitting expands into a "Review Order" step with an order-summary sentence (using `pendingCost()` so the dollar figure always matches the quantity, not per-share price), cash balance shown near the actions, and Cancel/Confirm split 50/50. `trade-form.spec.ts` was rewritten to match the new API (`cashBalance`/`hasHolding` inputs, no more `side` input, updated copy assertions) since the old spec predated this refactor. **Next step: open the PR for `feature/us-14-stock-details-redesign`; once merged, Milestone #12 (UI/UX Polish Pass) is complete and AWS deployment work (ADR 0005/0006/0014/0016/0017) can begin.**

Every MVP user story (US-1–US-9) is implemented; before deploying we're doing a UI/UX polish pass. AWS deployment (already architected — ADR 0005/0006/0014/0016/0017, not yet executed) stays blocked until this pass is done.

A manual test pass of the running app was scoped into **Milestone #12 (UI/UX Polish Pass)** — 5 stories:

1. **US-10 — Navigate between auth pages, and log out** — ✅ done, issue [#31](https://github.com/Efren707/toptrader/issues/31), merged via PR [#41](https://github.com/Efren707/toptrader/pull/41). Login/register cross-links, navbar logo → dashboard, logout wiring (frontend `AuthService.logout()` + backend `POST /auth/logout` fix).
2. **US-11 — Consistent, evenly-spaced navbar** — ✅ done, issue [#34](https://github.com/Efren707/toptrader/issues/34), merged via PR [#43](https://github.com/Efren707/toptrader/pull/43). Shared `Layout` shell route (see [ADR 0031](./adr/0031-authenticated-layout-shell-route.md)) guarantees the navbar on every authenticated page; `justify-content: space-between` fixes the dead gap before the account icon.
3. **US-12 — Correct search result row layout and click behavior** — ✅ done, issue [#35](https://github.com/Efren707/toptrader/issues/35), merged via PR [#45](https://github.com/Efren707/toptrader/pull/45). Price dropped from the row (ticker left / company name right only); result button now has `type="button"` so it no longer re-triggers the search form; flex/`space-between` layout rules moved from the unused `<li>` wrapper onto the button. Also fixed: the result dropdown not closing after a click, and the stock details page not refreshing when searching a new ticker from within itself.
4. **US-13 — Dashboard holdings as a list with day change, linking to stock details** — ✅ done, issue [#37](https://github.com/Efren707/toptrader/issues/37), merged via PR [#47](https://github.com/Efren707/toptrader/pull/47). `dp` threaded through `Quote`/`QuoteService`/`HoldingResponse` on the backend and the `Holding`/`Quote` frontend models; dashboard holdings render as a clickable list (ticker/quantity left, price/day-change right) navigating to `/stocks/:ticker`, replacing the old table.
5. **US-14 — Redesign the stock details page (layout, position stats, trade form)** — implemented on `feature/us-14-stock-details-redesign`, issue [#39](https://github.com/Efren707/toptrader/issues/39), PR not yet opened. 2-column layout, position stats block, single `TradeForm` with a Buy/Sell toggle and a full Review Order step. Frontend-only, as scoped.

Deferred out of this pass to a future backlog: general market news feed (dashboard + stock details — needs a new news data source), a profile page for editing/deleting an account, and a possible single-page auth redesign (login/register combined with client-side toggle instead of separate routes, black-background landing treatment, password-strength checkmark on the password field — floated 2026-07-28, not yet scoped).
