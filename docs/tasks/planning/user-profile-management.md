# User Profile Management

> Status: Not yet scoped. High-level backlog entry captured ahead of time — to be broken into GitHub issues, user stories, and acceptance criteria when picked up for implementation.

## Envisioned scope

- **Edit profile page** — lets a user update their own profile. Which fields are editable (username, email, password, avatar, etc.) is undecided; figure out at scoping time.
- **Delete account** — self-service account deletion. Cascade behavior (what happens to the user's holdings/transactions/friend relationships/leaderboard entries) is undecided; figure out at scoping time.
- **Profile icon** — an avatar/icon representing the user, shown wherever the account menu appears (e.g. navbar). Source of the icon (uploaded image, generated initials/avatar, fixed default) is undecided.
