# In Progress

Empty for now. This folder holds status/tracking docs for work that's actively being executed — as opposed to `docs/tasks/planning/` (scoped but not yet started) or `docs/tasks/completed/` (closed out, frozen). See [ADR 0040](../../adr/0040-work-tracking-docs-lifecycle.md) for the full convention.

A doc moves here from `docs/tasks/planning/` when work on it actually begins (e.g. `aws-infrastructure-implementation.md` moves here once its first section starts), and on to `docs/tasks/completed/` once everything in it is done.
